# ForeTac 视频使用指导

本文档说明 ForeTac 网页和演示材料中的视频文件如何区分、如何选择，以及四格片头的生成规则。后续替换或重新编码视频时，应先阅读本文档。

## 文件层级

### 1. 原始备份

原始备份使用 `_raw.mp4` 后缀，位于 `static/videos/`：

```text
board_real_raw.mp4
vase_real_raw.mp4
card_real_raw.mp4
chip_real_raw.mp4
```

这些文件只用于归档、重新编码和重新裁剪，不直接用于网页。不要删除或覆盖它们。

### 2. 网页优化源视频

网页使用的任务视频位于 `static/videos/`：

```text
board_real.mp4
vase_real.mp4
card_real.mp4
chip_real.mp4
```

它们是经过网页播放优化的 H.264 文件，通常为 1280×720、24 fps。对应的可视化视频使用 `*_viz.mp4`，其原始备份使用 `*_viz_raw.mp4`。

任务视频的网页版本和 `_raw` 版本必须成对保留。替换视频时，应从 `_raw` 重新生成网页版本，不要反复压缩已经压缩过的网页版本。

### 3. Overview 文件夹中的源副本

`static/videos/overview/` 中的 `source_*` 文件是构建 Overview 时使用的副本：

```text
source_board_real.mp4
source_board_real_raw.mp4
source_vase_real.mp4
source_vase_real_raw.mp4
source_card_real.mp4
source_card_real_raw.mp4
source_chip_real.mp4
source_chip_real_raw.mp4
```

它们便于独立归档和复现 Overview，但不是另一套不同的视频源。真正的任务视频源仍在上一级 `static/videos/`。

## 四格片头

最终四格片头是：

```text
static/videos/overview/hero_montage_no_title.mp4
```

它是 1280×720、12 秒的视频，排列顺序为：

```text
左上：Board wiping
右上：Vase wiping
左下：Card swiping
右下：Chip grasping
```

每个单格也有独立文件：

```text
hero_board_tile.mp4
hero_vase_tile.mp4
hero_card_tile.mp4
hero_chip_tile.mp4
```

这些单格文件都是 640×360、12 秒，可以单独播放或用于重新拼接。

### 为什么没有 `4x speed` 等标注

这些标注位于源视频顶部的录制标签区域。生成四格片头时，脚本进行了空间裁剪：

- Board、Vase：`crop=996:560:142:76`
- Card、Chip：`crop=iw:ih-76:0:76`

两种裁剪都去掉了顶部 76 像素，因此任务名、`4x speed` 和灰边不会进入最终片头。视频画面没有被涂抹，源视频和 `_raw` 备份仍保留这些标注。

此外，四个视频并不是都从第 0 秒开始截取：

| 任务 | 起始时间 | 截取时长 |
| --- | ---: | ---: |
| Board | 5 s | 12 s |
| Vase | 3 s | 12 s |
| Card | 1 s | 12 s |
| Chip | 2 s | 12 s |

因此四格片头是经过时间选择和空间裁剪的展示版本，不是四个源视频的原始首 12 秒。

## 不同场景如何选文件

| 使用场景 | 应使用 |
| --- | --- |
| 网页任务行的左侧真实视频 | `static/videos/*_real.mp4` |
| 网页任务行的右侧触觉可视化视频 | `static/videos/*_viz.mp4` |
| 保留原始画面、重新编码或重新剪辑 | `static/videos/*_raw.mp4` |
| 网页顶部四格片头 | `overview/hero_montage_no_title.mp4` |
| 网页 Overview 视频（当前） | `overview/ForeTac_video_keyframes_v2 - czy1007_x264_v3.mp4` |
| 上一版约 9 分 7 秒 Overview 导出 | `overview/foretac_overview-1007.mp4` |
| 旧版 45 秒 Overview 导出 | `overview/foretac_overview.mp4` |
| 单独展示某个无标注任务片段 | `overview/hero_*_tile.mp4` |
| 查看源片段及其标签 | `overview/source_*_real.mp4` 或上一级对应文件 |
| PPT 首屏视频 | `overview/hero_montage_no_title.mp4` |

网页不要直接引用 `_raw.mp4`，也不要把四格片头当作单个任务视频使用。四格片头中的时间起点和画面裁剪是为首页视觉展示选择的。

## 重新构建

从网页仓库根目录执行：

```bash
bash tools/build_v3_media.sh
```

脚本会：

1. 从 `static/videos/*_real.mp4` 读取四个任务视频；
2. 按上表的时间起点截取 12 秒；
3. 按任务应用裁剪参数；
4. 生成四个 `hero_*_tile.mp4`；
5. 拼接为 `hero_montage_no_title.mp4`；
6. 生成对应 poster 和 Overview 视频资源。

如果源视频发生变化，应先确认 `_raw` 备份仍存在，再重新生成网页版本，最后重新执行此脚本。不要手工修改最终四格视频来“修掉”标注，因为这样会破坏可复现性。

## 修改前检查

重新编码或替换视频前，至少检查：

- 左右任务视频的时长是否一致；
- 视频是否为 H.264、`yuv420p`、Fast Start；
- 浏览器是否能正常加载、暂停、继续和循环播放；
- 四格片头是否仍为 1280×720、12 秒；
- 四个单格是否仍为 640×360、12 秒；
- 物体和接触区域是否没有被裁掉；
- 源视频中的标签是否只通过裁剪去除，而不是覆盖或涂抹；
- poster 是否与实际视频的第一段内容一致。

网页视频加载、排查以及 Overview 重建和验证记录保留在本地工作区的 `midocx/` 中。
